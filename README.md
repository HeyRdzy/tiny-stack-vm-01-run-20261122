# tiny-stack-vm-01

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/tiny-stack-vm-01-run-20261122)
[![license](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![node](https://img.shields.io/badge/node-22-brightgreen)](https://nodejs.org)

A tiny stack virtual machine for make.fun's tiny-stack-vm-01 (ISA v1): 32-bit
wrapping values, a 256-value stack, calls, 256 words of memory, input/output,
and all ten traps. Runs every program in a set and writes each answer's
`stdout.bin` and `exit.txt`. Practice score: **1,000,000** (40/40).
